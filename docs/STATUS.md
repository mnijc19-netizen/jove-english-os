No key is needed for built-in demo listening, local recording and basic reviews.
2. Desktop and mobile acceptance used Chromium, including Pixel 7 emulation. Synthetic test microphone input verifies browser recording/storage behavior, not the owner's physical microphone or every mobile browser. Dedicated phoneme/acoustic scoring is intentionally not fabricated.
3. Stay online on the first visit until Ready for offline practice appears. An early pre-release tab may need one manual refresh after saving work to acquire the corrected updater. Subsequent first-install update behavior passed the real public test.
4. Learning data stays in this browser without automatic cloud sync. JSON backups exclude secrets and audio blobs; download important original recordings separately. Demo audio is clearly labeled synthetic, not natural-speaker or standardized proficiency evidence.
