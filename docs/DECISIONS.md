# Decisions

- 2026-09-13 approved multilingual plan: adopt the display name **Jove Language OS**, one site/account with independent English and Japanese learning spaces, not a copied second project. Retain the repository URL, PWA scope and local database identity. English continuous external-course supply precedes language isolation and a Japanese-specific Can-do curriculum. Shared retrieval/spacing/output tools do not justify English-only tokenization, English prompts, blended skill scores or assumed kanji mastery. AI assists language work; basic planning/save/review remain usable without it. No automatic acoustic scoring requirement. Stop equivalent paid retries without new evidence and report blockers early. The current objective and acceptance order are in `FINAL_UPGRADE.md`.

- 2026-09-13 owner scope amendment: prefer external publisher playback/links with automatic selection and in-site guided practice over bulk hosted audio. Remove mandatory automatic acoustic scoring; retain reference listening and recorded retries. Clicks/self-reported external listening cannot become objective playback, comprehension or pronunciation evidence. Existing rejected clips and financial history remain untouched. See the superseding section of `FINAL_UPGRADE.md`; all other learning/sync/security/release requirements remain.

- 2026-09-12 route focus: move normal title focus after Vue's actual DOM update, not a fixed80ms timer. Preserve an editor/new interaction's focus, ignore failed/stale navigation, and retain cold-start/skip-link access. The previous callback deterministically stole focus after editing began in both Chromium and WebKit; delaying/retrying browser tests would not repair that user interaction. No learning evidence, save condition or visual layout is changed.

- 2026-09-12 HPR transport: use the publisher-listed two-week MP3 RSS at `https://hackerpublicradio.org/hpr_rss.php`, preserving the source identity, rights, older Ogg rules and original enclosure provenance. The [official syndication page](https://hackerpublicradio.org/syndication.html) offers both formats. Actual episode4725 MP3 is18,628,209 bytes and its30–90s frame window passes the existing bounded clipping contract; the24,212,340-byte Ogg needs unsupported packet decoding. Select the publisher's format instead of synthesizing/transcoding human speech or claiming an Ogg decoder. A validated same-episode enclosure uses only the previously registered CDN. Normal source configuration/revision invalidation must retain existing records; no direct reset/cleanup is authorized by this decision. This does not solve every oversized publisher file or establish acoustic/lesson quality.

- 2026-09-08 automatic learning continuity: keep the existing `learn` task kind/schema, with stable `:reading` and `:chunks` assignment IDs. Old unsuffixed learn IDs retain their previous language-task and draft semantics. Reading and deliberate-language budgets no longer collapse into one slot. Shared route construction follows the next saved assignment; free Listen retains its original material/source-session path. Source sessions/events remain the evidence authority, not a query-string label. Reading retry may release Continue only after the exact saved snapshot commits, with original task/material/assessment identity and teardown fences. Expand native WebKit tests to the longitudinal learning journeys as well as browser capability/layout tests.
- 2026-09-08 final upgrade: the owner's 47-section instruction explicitly replaces V1 no-auth/no-cloud exclusions. Keep Vue, Dexie, routes, UI and Pages; add a dedicated Supabase service layer. Production AI/Speech keys are server-only; BYOK remains optional advanced fallback. Stable speaking target is General American, while listening accents broaden. Human speech becomes primary, generated material a bridge. Detailed traceability is `FINAL_UPGRADE.md`. No other project's backend or global configuration is in scope.

- 2026-09-07: user authorized full autonomous implementation, independent review, fixes, git push and Pages deployment. Complete V1 preserved; no intermediate milestone is Definition of Done.
- Model audit: global default Sol/max retained. Project default Astra/ultra added; actual active branched rollout confirms `gpt-6-astra`, `ultra`. Original pre-switch rollout records Sol/max and is historical. Ancestor/global AGENTS only general coding rules; no inherited role files/requirements discovered in ancestor and known Windows configuration paths. Desktop state's inspected model fields do not override selection. Installed catalog lists Astra ultra. Project trusted. Unrelated role-routing project is not in this project's ancestry.
- 2026-09-08 audit recheck: [official Codex configuration precedence](https://learn.chatgpt.com/zh-Hans/docs/config-file/config-basic) confirms trusted project overrides precede user defaults. Local configuration/catalog and the active branched runtime still show Astra/ultra. No global configuration was changed. API model documentation is not used to override the desktop runtime's supported effort values.
- Use hash routing, Vite base and SW scope `/jove-english-os/`. Use mature FSRS, independent modality cards; qualitative evidence confidence and deterministic algorithm remain explainable.
- 2026-09-08: real production and two-artifact local tests found that the first-install document's Workbox instance retains `isUpdate=false`, even when a later worker takes control. Handle native `controllerchange` after explicit Update now consent, and route the plugin reload callback through the same one-shot guard. Never automatically reload another tab's unsaved work. Test both initial uncontrolled and already-controlled documents; a test that reloads after installation alone misses this case.
- Update consent is recoverable: browser beforeunload protection may cancel navigation without throwing. Restore the update action after 2 seconds if the original document remains; bound stalled activation at 15 seconds. A later event cannot reload without renewed consent. Regression coverage cancels an actual browser dialog, saves the ongoing recording, retries, and verifies the original audio bytes remain identical.
- All seven main learning destinations plus Settings; Speak has four explicit modes. Tiny original curated demo scripts can be synthesized locally and labeled synthetic so no-key/offline works. Real imported audio is never relabeled as TTS. Do not pass generated examples off as retrieved authentic material.
- Plain CSS variables and reusable components satisfy styling requirements with less dependency surface; no mandatory Tailwind dependency in final execution specification.
- No live provider key is assumed. Dynamic catalog and deterministic mocked contract/failure tests proceed; request a key only if it is the sole remaining required gate. Keys only enter the user's browser.
