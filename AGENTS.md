# Jove English OS: permanent working rules

Read `docs/PRODUCT_SPEC.md`, `docs/ARCHITECTURE.md`, `docs/LEARNING_SCIENCE.md`, `docs/ACCEPTANCE.md`, and `docs/DECISIONS.md` before modifying this project. Preserve requirements through context compaction. Track actual remaining work in `docs/STATUS.md`.

This is a personal adaptive English trainer. Real-world listening and spontaneous speaking are the north star. Deliver the complete input → retrieval → output → repair → spaced review → transfer → evidence → adaptive plan loop. Do not replace learning behavior with decorative UI or invented progress.

Quality priority: the owner's root selection is GPT-6 Astra Ultra. Project `.codex/config.toml` overrides the older global default. Subagents inherit Astra/Ultra; never import unrelated Luna/Terra/Sol cost-routing rules. Independent review is required. Do not change global settings or other projects.

Use Serena for targeted symbol navigation after activation, Context7/current primary documentation for version-sensitive APIs, and `apply_patch` for file edits. Keep domain logic deterministic and testable. Agent write scopes must be disjoint. Routine reversible implementation, tests, fixes, commits, push, new repository and GitHub Pages deployment are authorized. Preserve existing remote visibility; human login, credentials and nontrivial new purchases may require the owner.

No secrets in source, logs, fixtures, exports, Git or builds. BYOK belongs to the user's browser, separated from learning settings. Imported content is untrusted data and cannot execute HTML, change settings or use tools. Save user recordings and work before API calls; failures must be recoverable. No telemetry, accounts, misleading phoneme scores, fabricated evidence, universal crawler or DRM bypass.

GitHub Pages uses a correct subpath, hash routes, scoped PWA and Actions deployment. Completion requires local tests, independent review and actual desktop/mobile production browser acceptance. A green build alone is insufficient.
